# من تراب القرية إلى آفاق الدوحة — ياسر بختيار

## نشر روی GitHub Pages
1. در GitHub یک Repository عمومی (Public) بسازید.
2. همهٔ محتوای این پوشه (`index.html`، پوشهٔ `images` و `.nojekyll`) را در ریشهٔ Repository آپلود کنید.
3. Settings ← Pages ← Source: «Deploy from a branch» ← شاخهٔ `main` و پوشهٔ `/ (root)` ← Save.
4. بعد از یکی دو دقیقه: `https://USERNAME.github.io/REPO-NAME/`
