# من تراب القرية إلى آفاق الدوحة — ياسر بختيار

## نشر روی GitHub Pages
1. در GitHub یک Repository عمومی (Public) بسازید.
2. همهٔ محتوای این پوشه (`index.html`، `images`، `fonts` و `.nojekyll`) را در ریشهٔ Repository آپلود کنید.
3. Settings ← Pages ← Source: «Deploy from a branch» ← شاخهٔ `main` و پوشهٔ `/ (root)` ← Save.
4. بعد از یکی دو دقیقه: `https://USERNAME.github.io/REPO-NAME/`

## فونت متن: Kitab
فونت Kitab (نسخ کلاسیک، مجوز OFL) از https://github.com/nuqayah/kitab-font بارگذاری می‌شود.
برای اطمینان بیشتر، `Kitab-Regular.ttf` و `Kitab-Bold.ttf` را در پوشهٔ `fonts` بگذارید (راهنما در `fonts/README.txt`).
عنوان‌ها: Reem Kufi — برچسب‌ها: Tajawal (Google Fonts).
